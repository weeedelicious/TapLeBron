# Cindy 创作思路（工作流设计方法论 · 持续迭代）

这是 Cindy 规划节点与连线方案（proposal）时的思路库。目标不是死记规则，而是理解"怎么把用户的创作意图拆成一条能产出高质量、且角色 / 风格一致结果的节点工作流"。遇到新情况要灵活套用；发现更好的思路，就补充到这里。

## 核心原则
- **先锁身份，再驱动变化**：先用高保真的图片模型（Nano Banana / gemini-3-pro-image）把角色 / 主体定下来，再让后续步骤（换装、换景、运动、视频）在这个锚点上变化，而不是每一步都从零重画。
- **给弱模型更强的视觉锚点**：视频模型（Seedance 等）的角色一致性远弱于图片模型，且只靠文字提示锁不住身份。要让角色在视频里"动起来还不走形"，就要给它尽可能强的视觉参考（首帧、多视角参考图），而不是只给一句提示词。
- **能拆就拆**：复杂需求拆成"锁身份 → 生成支撑素材 → 用素材驱动最终产出"的多节点链路，每一步都用最擅长该步骤的模型 / 模式。
- **选对模式**：视频节点里，`图生视频(i2v / 首帧)` = 从这张图开始动、身份最稳；`首尾帧` = 控制起止画面；`多模态(参考)` = 只在需要松散借鉴时才用（它会用自己的画风重画，容易走形）。Cindy 目前不能直接设置视频节点的模式，但应在回复里明确建议用户切到合适的模式。

## 典型思路：让参考角色在视频里保持一致地运动
适用场景：用户已有一张满意的角色图（如"兔耳女孩绿色衣服"），想让这个**同一个角色**在视频里做动作（走路、摔倒等）。若直接把图丢进视频节点，角色会被视频模型换画风、改比例。

推荐工作流：
1. **定妆图**：一张高质量、角色造型明确的参考图（已有，或先用图片节点生成）。
2. **生成三视图**：用图片节点，基于定妆图生成该角色的**三视图（正面 / 侧面 / 背面）**，提示词写明"基于参考图，生成同一角色的三视图，保持造型、配色、比例完全一致"。三视图给了后续步骤多角度的身份信息。
3. **两张一起喂给视频节点**：把**定妆图 + 三视图**都连到视频节点。
4. **视频提示词点明三视图**：在视频提示词里明确说明"附图中包含该兔耳女孩的三视图，请严格按三视图还原角色的造型与比例"，再描述要做的动作与运镜。
5. **优先图生视频(首帧)**：让定妆图作为首帧、三视图作为角色参考，一致性最好；并在回复里提醒用户把视频节点切到「图生视频(首帧)」。

本质："用图片模型产出稳定的多视角身份素材，再拿去喂给一致性更弱的视频模型"。同样套路可推广到：换装后保持人脸、换景后保持主体、系列分镜保持同一角色等。

## 可复用的支撑素材套路
- **三视图 / 转身图（turnaround）**：锁角色造型与比例。
- **表情表 / 姿势表**：锁五官与动态的一致性。
- **关键帧图**：先用图片模型把关键画面画准，再用视频的首尾帧驱动过渡。
- **换装 / 换景中间图**：先在图片模型里改好，再作为视频或下一步的参考。

## 何时用哪种视频模式
- 要"同一张图动起来" → 图生视频(i2v / 首帧)。
- 要"从 A 画面过渡到 B 画面" → 首尾帧。
- 只要氛围 / 风格借鉴、不要求身份精确 → 多模态(参考)。
- 纯凭想象、无参考 → 文生视频。
