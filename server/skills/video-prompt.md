# 视频提示词技能（Cindy 生成 video 节点 prompt 时必读）

你在为画布中的 video（视频生成）节点撰写 `prompt` 与 `settings` 时，必须结合本技能说明和你与用户的对话上下文理解后再生成。视频提示词的核心是描述"**随时间发生的动态镜头**"，而不是一张静态图。

## 默认参数（写进节点 settings，而不是只写进 prompt）
- 清晰度 resolution：默认 **720P**；仅当用户明确指定 480P / 1080P / 4K 时才改。
- 画幅比例 ratio：默认 **16:9**；仅当用户明确指定其它比例（9:16 / 1:1 / 4:3 / 3:4 / 21:9 等）时才改。竖屏用 9:16，横屏 / 电影感用 16:9。
- 时长 duration：如用户未指定，默认约 **5 秒**（合法范围 4–15 秒的整数）。
- 数量 count：默认 1。
- 即使用户没提，也要把上面的默认清晰度和比例填进 settings。

## 角色参考（重要）
- 如果有角色 / 人物参考（连到该视频节点的参考图，或用户指定要沿用的角色），必须**完全还原角色的比例与造型**：体型比例、五官、发型发色、服装配饰、整体风格在整段视频中保持一致，不要重新设计，也不要让角色在运动中变形 / 漂移。
- 只让参考未约束的部分发生变化（动作、镜头运动、场景、光线），角色本体和造型保持稳定一致。
- 在 prompt 中明确写"保持参考角色的造型与比例一致、贯穿全片"。

## 提示词写法（常规补充）
一条好的视频提示词通常覆盖：主体与动作 → 镜头运动 → 场景 / 环境 → 光线与色调 → 风格 / 氛围 → 节奏与时长。
- 动作与时间：描述主体在这几秒内做了什么、如何演变（起始 → 过程 → 结束）。
- 镜头运动：点明运镜方式（推进 / 拉远 / 横摇 / 俯仰 / 跟拍 / 环绕 / 手持 / 固定机位）与速度。
- 场景与光线：环境、时间、光氛围、色调。
- 风格与氛围：写实 / 电影感 / 动画 / 纪录片等；需要时点明质感与调色。
- 保持单一连贯镜头，除非用户要求多镜头 / 转场；避免自相矛盾的运动描述。
- 语言用简洁中文即可，除非用户要求特定语言。

## 不要做
- 不要只写静态画面而不写动作与镜头运动。
- 不要臆造与参考角色冲突的造型 / 比例。
- 不要把比例 / 清晰度 / 时长只写进 prompt 文字而漏填 settings。
