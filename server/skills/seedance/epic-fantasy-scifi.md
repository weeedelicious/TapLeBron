# 奇幻科幻大场面

先让人看懂尺度，再给能量。奇观要服务一个动作，不要只堆特效层。

## 结构
- 小物体或人物建立比例
- 揭示巨大空间/造物/天空现象
- 一次能量释放或结构运动
- 人物在奇观下的反应

## 必须写清
- 空间尺度（人物对比建筑/飞船/巨兽）
- 能量的来源、颜色、运动方向
- 空气尘埃、体积光、碎片的物理
- 镜头从人推向场面或从场面落到人

## 参考素材
- 角色锁身份，避免淹没在特效里认不出
- 概念图继承设计语言，不继承死构图

## 禁止
- 无限层爆炸没有主体
- 风格在魔法、硬科幻、克苏鲁之间乱跳
- 无视节点时长去写史诗三幕

## 空提示词
默认：角色站在高台，面前巨大造物苏醒，能量沿结构攀升，角色抬手。
