# 动漫与风格化画风固定

画风必须写成可执行规则，否则会塌回通用 CG。线、面、眼型、上色方法都要锁。

## 结构
- 先写画风参数：线宽、阴影分阶、眼睛比例、头发材质
- 再写角色表演
- 镜头用动画常用语言（固定切、轻微推、速度线仅在需要时）

## 必须写清
- 2D 赛璐璐 / 厚涂 / 日式剧场版 等一种，不要混
- 排除清单：写实皮肤毛孔、真实摄像机散景、真人比例
- 动作的动画感（预备、过冲）但关节不能断

## 参考素材
- 角色图锁人设：发型、瞳色、服装图案
- 不要把真人照片参考理解成要拍真人

## 禁止
- 中途变成真人实拍
- 每秒换一种画风
- 只写“动漫风”三个字

## 空提示词
默认：一位人设明确的少年/少女在放学教室望向窗外，风吹动头发，画风锁死。
