# 早年 DV 家庭录像

MiniDV / 家用摄像机气质：软对比、轻微过曝、色偏、时间码感，内容是家庭或旅行现场，不是恐怖伪纪录片（除非用户要恐怖）。

## 结构
- 开机不稳，先对焦再找到人
- 家人或朋友做一件日常事
- 拍摄者会说话、会跟丢再找回

## 必须写清
- 磁带噪点、略低锐度、自动曝光抽动
- 4:3 或家用 DV 取景习惯（可以在画面内体现，不改节点比例设置）
- 过曝的窗户、偏绿或偏暖的室内灯
- 变焦是摄像机变焦，不是电影推轨

## 参考素材
- 人物锁身份，但画质要按 DV 劣化，不要把参考图的商业精修带进视频

## 禁止
- IMAX、变形宽银幕、现代 log 调色
- 稳定的广告运镜
- 无故变成找到的诅咒录像带

## 空提示词
默认：2000 年代初客厅生日，家人手持 DV 拍吹蜡烛，对焦来回拉。
