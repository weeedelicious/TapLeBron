# 逐秒时间轴分镜脚本

把整段视频写成连续、不重叠、覆盖完整时长的时间轴。每段只允许一个主要动作和一个明确镜头意图。

## 结构
- 开场建立人物与空间
- 中段推进动作或信息
- 收束落幅，不要突然黑场

## 必须写清
- 每段起止秒数
- 每段主体在做什么
- 每段机位/运镜，中段切换时写清如何接上
- 人物朝向、出入画方向连续

## 参考素材
- 有 @图片/@视频 时，先写该时段继承什么
- 分镜图按从左到右、从上到下的顺序对应时间段

## 禁止
- 时间段重叠或留下空白
- 同一秒里两个主动作或两次运镜
- 把时长改短

## 空提示词
按节点名给一个具体情境，切成 3 段左右覆盖总时长。
