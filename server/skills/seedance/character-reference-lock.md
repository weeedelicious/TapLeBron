# 参考图身份锁定

核心任务是让人物在整段里保持同一张脸、同一套造型。动作和镜头可以变，人不能变。

## 结构
- 先锁定身份：五官、发型发色、体型比例、服装配饰、年龄气质
- 再写动作与走位
- 最后写镜头，避免大特写把脸画飞，除非参考图就是特写

## 必须写清
- 每位出场人物对应哪张 @图片
- “完全还原参考造型，贯穿全片，禁止换脸换装”
- 多人时谁在画面左侧/右侧，避免身份对调

## 参考素材
- 人物参考只继承外貌与服装，不继承原图姿势，除非用户要求
- 场景参考只继承空间和光线，不覆盖人物身份

## 禁止
- 杜撰不存在的参考编号
- 美化五官、改发色、换衣服
- 让角色在运动中体型漂移

## 空提示词
有参考图就让图中人物做该片种最稳的小动作（走路、转头、举手）；没参考图则写清一个可识别的人物并在 warnings 说明缺少身份锁定图。
