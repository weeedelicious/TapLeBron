# 对白与表演节拍

有效载荷是台词和反应，不是风景。口型、停顿、听者反应要对齐。

## 结构
- 谁在对谁说话
- 一句短对白 + 听者反应
- 可选第二句把关系推进一步
- 用表情或停顿收，而不是大远景

## 必须写清
- 原句台词（加引号），不要改用户给的词
- 说话人的情绪和音量
- 听者眼神、呼吸、微动作
- 景别以中近景和过肩为主

## 参考素材
- 每个人物一张参考就锁谁是谁
- 不要让 A 的脸在反应镜头里变成 B

## 禁止
- 长篇独白超出时长
- 口型含糊却写很多字
- 对白和动作抢同一秒的主运动

## 空提示词
默认两句生活对白（惊讶来访或迟到道歉），并在 warnings 标明台词是扩写。
