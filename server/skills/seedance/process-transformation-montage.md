# 流程与变换蒙太奇

表现制作、变装、空间改造、前后对比。节奏靠步骤，不靠乱切。

## 结构
- 原状态
- 2–4 个关键步骤（动手、工具、中间态）
- 完成态展示

## 必须写清
- 每一步改变了什么
- 工具和手的接触
- 时间如何压缩（跳切或匹配剪辑），但总时长仍覆盖节点 duration
- 前后物体是同一物，位置逻辑自洽

## 参考素材
- 开始状态图 / 结束状态图要分别声明
- 过程如果没有参考，用合理工艺补全并在 warnings 说明

## 禁止
- 无过程的瞬间变身（除非用户要魔法）
- 步骤顺序颠倒
- 完成态和开始态不是同一主体

## 空提示词
默认：一件普通物品被逐步改造为精致完成态，最后一拍对比展示。
