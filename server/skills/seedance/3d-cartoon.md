# 3D 卡通角色短片

体积感卡通，不是写实三维人。比例可以头大身小，表演夸张，材质干净。

## 结构
- 角色亮相，体积和剪影清楚
- 一个夸张表演动作（伸懒腰、滑倒、欢呼）
- 表情和身体跟随结束

## 必须写清
- 体型比例
- 材质：塑料感、羊毛、糖果色油漆等一种
- 灯光像动画电影，柔和全局光 + 明确主光
- 物理可以略卡通，但不能穿模

## 参考素材
- 角色参考锁配色和关键特征
- 允许把真人参考卡通化，但要在 prompt 声明，且五官特征可辨认

## 禁止
- 写实皮肤和毛孔
- 恐怖谷比例
- 无意义的镜头环绕超过整段时长

## 空提示词
默认：一个圆润的 3D 卡通角色在明亮房间里发现礼物，夸张欢呼。
