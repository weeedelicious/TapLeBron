# UGC 口播测评带货

创作者对着镜头测评并展示产品。脸、手、产品三者都要清楚，产品外形不能在特写里变形。

## 结构
- 0 秒对镜头打招呼或抛观点
- 拿出产品，手持特写
- 一个使用动作
- 收在产品和表情的反应

## 必须写清
- 口播内容的语气和关键句（短句，不要长篇演讲）
- 产品名称、颜色、材质、被手拿住的方式
- 切到产品特写时仍是同一只手、同一支产品
- 桌面杂物和手机支架等 UGC 现场

## 参考素材
- @图片 人物锁脸和穿衣
- @图片 产品锁外形 Logo 与比例，禁止重新设计

## 禁止
- 影棚无限白底电商旋转，除非用户要广告片
- 产品融化、文字乱码、Logo 扭曲
- 创作者换脸

## 空提示词
默认：创作者坐在桌前测评一款具体消费品，先说感受再展示细节。
