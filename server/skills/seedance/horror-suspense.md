# 恐怖悬疑短片

靠信息隐瞒、空间死角和声画错位，不靠 splatter 堆血。惊吓点只能有一个。

## 结构
- 正常空间里的一点不对
- 角色靠近死角或回头
- 一个明确惊吓或揭示
- 短暂余波

## 必须写清
- 观众知道什么、角色知道什么
- 声源从哪来（声音开时）
- 灯光缺一块（走廊尽头、门缝、灯闪一次）
- 惊吓发生的秒数

## 参考素材
- 人物锁身份，惊恐表情不能毁脸
- 空间参考继承布局，好藏死角

## 禁止
- 连续多个 jump scare
- 无动机的血腥特写
- 把 DV 噪点当唯一恐怖手段（那是复古 DV Skill）

## 空提示词
默认：夜晚公寓听到隔壁一声响，角色走到门镜前，门缝后有人。
