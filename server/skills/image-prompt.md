# 图片提示词技能（Cindy 生成 image 节点 prompt 时必读）

你在为画布中的 image（图片生成）节点撰写 `prompt` 与 `settings` 时，必须结合本技能说明和你与用户的对话上下文进行理解，再生成最终提示词。不要生搬用户原话，而要把需求翻译成清晰、可被图像模型执行的画面描述。

## 默认参数（写进节点 settings，而不是只写进 prompt）
- 清晰度 resolution：默认 **1K**；仅当用户明确指定 2K / 4K 时才改。
- 画幅比例 ratio：默认 **16:9**；仅当用户明确指定其它比例（1:1 / 9:16 / 3:4 / 4:3 等）时才改。竖屏 / 手机 / 海报常用 9:16 或 3:4，横屏 / 场景 / 电影感用 16:9。
- 数量 count：默认 1，除非用户要多张。
- 即使用户没提清晰度和比例，也要把上面的默认值填进 settings，让节点直接带上正确参数。

## 角色参考（重要）
- 如果画布里有角色 / 人物参考图（连到该图片节点的参考图，或用户明确指定要沿用的角色），必须**完全还原该角色**：五官、发型、发色、体型比例、服装、配饰、整体风格都要与参考保持一致，不要擅自重新设计或改动角色的既定特征。
- 只改变参考未约束的部分（如姿势、场景、光线、镜头），角色本体保持一致。
- 在 prompt 中明确写出"保持参考角色的外形 / 服装 / 比例一致"这类约束，降低模型漂移。

## 提示词写法（常规补充）
一条高质量图片提示词通常覆盖：主体 → 场景 / 环境 → 构图与视角 → 光线 → 色彩 / 色调 → 风格 / 媒介 → 氛围情绪 → 细节与质感。
- 具体、可视化：用画面语言描述，避免抽象含糊；把最重要的主体放在最前面。
- 视角与构图：需要时点明景别（特写 / 中景 / 全景）、机位与角度（俯拍 / 平视 / 仰拍）、构图（居中 / 三分 / 对称）。
- 光线与色彩：说明光源、时间、氛围（柔光 / 硬光 / 逆光 / 黄昏暖调 / 冷色霓虹等）。
- 风格 / 媒介：写清写实摄影、插画、3D、水彩、赛博朋克等；需要时点明镜头 / 胶片质感。
- 保持一致、不自相矛盾；不要堆砌"高质量、大师作"等空词，用具体细节代替。
- 语言用简洁中文即可（模型支持中文）；除非用户要求特定语言。

## 不要做
- 不要臆造与参考角色冲突的特征。
- 不要在没有要求时输出多张（count 默认 1）。
- 不要把比例 / 清晰度只写进 prompt 文字而漏填 settings。
