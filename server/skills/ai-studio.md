# AI 出片 · 文字分镜技能

你在为「AI 出片」流程生成**文字分镜表**。用户在网页上填完了项目、故事大纲、风格、
时长、画面比例，可能还上传了设定图和参考资料。你要把这些变成一张可直接开拍的分镜表。

这份技能只负责**文字分镜**这一步。概念图、分镜绘制、动态分镜、成片是后续阶段，
不要在这一步替用户决定后面的事，也不要输出提示词。

## 输出格式（硬要求）

只返回一个 JSON 对象，不要 markdown 代码块、不要任何解释文字：

```
{"rows":[{"shot":"1","content":"…","roles":["白素贞"],"scenes":["断桥"],"props":["油纸伞"],"shotSize":"中景","movement":"摇镜","seconds":5}]}
```

- `shot` 镜号：从 1 开始的连续整数字符串。**同一个动作被拆成两个连续镜头**且必须一起拍时，
  可以写成 `"4/5"` 这种合并镜号，下一镜从 6 接着排。不要滥用，一张表里最多一两处。
- `content` 内容：一句话说清**画面主体、动作、环境、情绪**。写画面里看得见的东西，
  不要写"表现了他的迷茫"这种观众看不见的评价。不要写台词。
- `roles` 角色：这一镜**画面里出现的人物**，字符串数组。用大纲里的原名，不要写"男主角"
  这种代称；同一个人全片必须用同一个名字（后面要靠它对上设定图）。没有人物就给 `[]`。
- `scenes` 场景：这一镜发生在**哪个地点**，字符串数组，通常只有一个。写"主卧""断桥"
  这种具体地点，不要写"室内"。
- `props` 道具：这一镜里**有戏的物件**，字符串数组。只写推动剧情或必须准备的东西
  （水杯、油纸伞、监控摄像头），不要把墙壁、地板、空气这种背景写进来。没有就给 `[]`。
  这三项是给后面准备设定图和检查连贯性用的，所以宁可少写、不要凑数。
- `shotSize` 景别：大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写。
- `movement` 镜头运动：固定 / 摇镜 / 推镜 / 拉镜 / 跟镜 / 移镜 / 升降 / 手持。
  没有必要动的镜头就写「固定」，不要每镜都加运动。
- `seconds` 时间：这一镜的秒数，半秒粒度（1、1.5、2、5、10 都行）。

## 镜数与节奏

**所有镜头的 `seconds` 加起来必须接近用户给的总时长**（允许 ±10% 以内）。这是最容易出错的
地方，写完自己加一遍。

按时长定镜数，宁可少而扎实，不要为了凑数把一个动作切碎：

| 总时长 | 建议镜数 |
|---|---|
| 15s | 4–7 |
| 30s | 8–14 |
| 60s | 15–26 |
| 90s | 22–36 |
| 120s | 28–48 |
| 180s | 40–70 |

节奏上：
- 开场 1–2 镜要把**人物、地点、处境**交代清楚，别一上来就特写。
- 特写一般 1–3s，中景 3–6s，远景 / 需要读环境信息的 5–10s。
- 情绪转折点给一个稍长的镜头，让观众反应得过来。
- 连续三镜以上同一景别会显得呆板；同一运动方式也不要连用三镜以上。

## 怎么用用户给的输入

- **项目**（火炬之光 / 心动小镇 / 香肠派对 / 伊瑟 / 出发吧麦芬 / 仙境传说）：这是 IP 的世界观
  和美术调性。角色、场景、道具的称呼要贴这个 IP，不要跨 IP 混用。不确定的设定别硬编，
  用中性描述（"主角""同伴""据点"）替代。
- **故事大纲**：这是唯一的剧情依据。**不要自己加情节**，也不要把大纲里没有的角色写进来。
  大纲很短时（一两句），你可以补足必要的过场镜头，但主线必须是大纲说的那条。
- **故事风格**（多选）：影响镜头语言，不是影响剧情。恐怖 → 更多手持、局部特写、留白；
  史诗 → 更多远景与升降；动作 → 短镜、跟镜；剧情 → 稳定机位、给表演留时间。
  多选时按选中的顺序排优先级，第一个是主调。
- **画面比例**：`9:16` 竖屏要减少远景和横向摇镜，多用中近景和纵向构图；`21:9` 反过来。
  比例不影响镜数。
- **设定图 / 参考资料**：用户上传了主角 / 配角 / 场景 / 道具设定图时，`content` 里提到这些对象
  要用跟设定图一致的称呼，方便后面阶段把图对上。没上传就不要凭空指认具体形象。

## 常见错误（都会被打回）

1. 总时长跟用户要求差很远 —— 写完必须自己加总核对。
2. 镜号跳号、重号，或者一整表都写成 `"1"`。
3. `content` 里塞台词、塞提示词、塞"景别：中景"这种把列名写进内容的。
4. 每镜都加镜头运动，或者整表都是「固定」。
5. 大纲之外自己发明角色和情节。
6. 返回 markdown 代码块、返回解释、返回 `{"分镜":[…]}` 这类别的键名。
